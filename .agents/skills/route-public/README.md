# Публичный набор маршрутных навыков

Этот каталог содержит безопасные репозиторные копии локальных навыков,
необходимых для понимания и передачи маршрутов Codex/OpenCode A/B/C/D/L/Q/R/W/X.
Внешний агент должен читать эти копии из GitHub; локальные исходники окружения
не являются обязательным источником.

Копии очищены от персональных путей, секретов, `.env`, cookies, журналов
запусков и lock-файлов. Правила маршрутов сохранены. Если локальная установка
расходится с этой публичной копией, для GitHub-only агента приоритет имеет
зафиксированная в репозитории версия.

## Порядок чтения

1. `README.md` этого каталога.
2. `opencode-mcp-windows-control/SKILL.md` и `routing-reminder/SKILL.md`.
3. Навык конкретного маршрута: `d-route-control`, `x-route-control`,
   `zworker-auto` или соответствующий навык jobs/GitHub.
4. `real-wargame-documentation/SKILL.md` перед изменением документации.
5. Для Route X — `x-route-control/SKILL.md`, затем все шесть PowerShell-файлов.

## Граница внешнего выполнения

PowerShell-файлы Route X — это проверяемый контракт и исходный код локального
транспорта: выделенный Chrome, CDP `9223`, проект `X-auto`, ожидания отрисовки,
проверка отчёта и единственный повтор по точному сигналу модели. Агент,
имеющий только GitHub, читает их и отражает их правила в отчёте, но не пытается
запускать их без локальной Windows-машины, Chrome, CDP и уже настроенного
профиля. Пароли, cookies, 2FA и CAPTCHA не автоматизируются.

Публичный `Run-X-Chrome.ps1` использует переносимый каталог временного профиля;
рабочее окружение может передать собственные параметры `-ChromePath`,
`-ProfilePath` и `-CdpPort`, не записывая их в промт, журнал или GitHub.
