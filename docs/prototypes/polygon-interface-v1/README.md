# Прототип интерфейса полигона

Автономный интерактивный прототип согласованной компоновки интерфейса.

Открыть: `index.html`.

## Зафиксированная основа

- центральная карта остаётся главным рабочим пространством;
- верхняя панель управляет запуском, файлом эксперимента, общими редакторами и визуальными слоями;
- левая панель содержит рабочие разделы;
- правая панель только показывает состояние выбранного юнита;
- обе боковые панели независимо сворачиваются и меняют ширину;
- контекстное меню карты зависит от выбранного рабочего раздела;
- неразобранные разделы оставлены пустыми.

## Редактор юнита

В прототип добавлен компактный двухуровневый редактор:

- частые настройки находятся в левой панели;
- кнопка `Подробно` закреплена сверху и всегда видна;
- список юнитов скрыт за отдельной кнопкой с поиском;
- позы, перемещение и поворот представлены иконками;
- архетип назначает исходный набор профилей;
- профиль поведения, внимания и движения можно заменить для отдельного юнита;
- показатели профилей в редакторе юнита доступны только для чтения;
- полные настройки открываются в отдельном компактном окне;
- создание, выбор, копирование, удаление, перемещение и поворот работают демонстрационно.

## Подробные настройки v3

- добавлен выбор управляющего Graph v2 и вариант `Без графа (пустой граф)`;
- показатели профилей показываются числами, единицами измерения и текстовой оценкой;
- добавлена отдельная вкладка `Черты бойца`;
- добавлен полный набор стартовых состояний;
- значения наследуются от архетипа или профиля;
- индивидуальное изменение отмечается и получает кнопку `↶` для возврата к исходному значению.

Это UX-прототип, а не готовый дизайн и не часть производственного интерфейса.
