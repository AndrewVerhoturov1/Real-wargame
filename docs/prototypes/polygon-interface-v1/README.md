# Прототип интерфейса полигона

Автономный интерактивный прототип согласованной компоновки интерфейса.

Открыть: `index.html`.

Зафиксировано в прототипе:

- центральная карта как основное рабочее пространство;
- верхняя глобальная панель запуска, файла, редакторов и визуальных слоёв;
- левая изменяемая палитра рабочих разделов;
- правая информационная панель выбранного юнита без редактирования;
- независимое сворачивание и изменение ширины панелей;
- контекстные действия карты, зависящие от открытого раздела;
- пустые состояния для ещё не проработанных разделов.

Это UX-прототип, а не готовый дизайн и не часть производственного интерфейса.
