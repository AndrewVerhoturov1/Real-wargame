# Отображение солдат видом сверху

## Goal

Исследовать и зафиксировать требования к читаемому отображению солдат видом сверху для тактической игры. Конкретный внешний стиль пока не выбран: исследование фиксирует требования и критерии, но не утверждает дизайн.

## Current focus

Составить проверяемые критерии:

- читаемый силуэт солдата;
- различение сторон боя;
- различение типов бойцов;
- различение оружия;
- различение состояний солдата.

## Key decisions

- Конкретный внешний стиль солдат пока не выбран.
- Исследование не утверждает дизайн: утверждение возможно только после отдельного явного решения пользователя.
- Рендерер показывает состояние игры и не является источником игровой истины.
