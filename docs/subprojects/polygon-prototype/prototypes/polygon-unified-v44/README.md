# Принятый прототип Полигона v44

Это точная репозиторная копия принятого автономного HTML-прототипа:

`polygon-map-editor-unified-v44-vegetation-seam-fix.html`

Внутренняя версия прототипа:

`polygon-map-editor-unified-v44-vegetation-live-seamless-tiles-20260808`

## Статус

Принят пользователем 10 августа 2026 года как текущая базовая версия подпроекта «Полигон».

Готовыми на этом рубеже считаются три главных рабочих раздела:

- `Редактор юнита`;
- `Редактор карты`;
- `Программа`.

`Серия`, `Метрики`, `Журнал`, единая правая контекстная панель и законченная верхняя панель **не считаются реализованными**. Их проектирование — ближайший этап подпроекта.

## Почему файл хранится пакетно

Исходный HTML имеет размер около 1,24 МБ. Чтобы сохранить точную принятую версию без ручного дробления исходного кода, используется тот же принцип, что и для принятого редактора программы:

1. исходный HTML сжат в gzip;
2. gzip закодирован Base64;
3. строка разбита на небольшие локальные JavaScript-файлы;
4. файл запуска объединяет части, распаковывает gzip через `DecompressionStream` и открывает восстановленный HTML.

Сеть и сервер для запуска не требуются. Нужно сохранить весь каталог вместе с подпапкой `payload`.

## Запуск

Открыть:

`polygon-map-editor-unified-v44.html`

в современном Chromium-браузере с поддержкой `DecompressionStream` (Chrome, Edge и т. п.).
