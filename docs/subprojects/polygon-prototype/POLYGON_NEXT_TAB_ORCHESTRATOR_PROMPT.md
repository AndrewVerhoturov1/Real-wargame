## Принцип работы с интерфейсом

Полигон — это рабочий инструмент для настройки и разбора эксперимента, а не декоративный экран.

Приоритеты:

1. понятность;
2. скорость работы пользователя;
3. информативность;
4. компактность;
5. визуальная и терминологическая согласованность с уже принятыми вкладками;
6. только после этого декоративность.

Не заполняй экран случайными красивыми карточками и графиками. Каждый элемент должен отвечать на конкретный вопрос пользователя или позволять выполнить конкретное действие.
