# ТЕКУЩАЯ ЗАДАЧА — «МЕТРИКИ»

`Метрики` должны стать конструктором того, что Полигон наблюдает, записывает, вычисляет, группирует, сравнивает и показывает в конкретном эксперименте.

Это не копия существующей панели текущих чисел Combat Lab.

Подробный продуктовый контракт записан в `METRICS_CONSTRUCTOR_PLAN.md`.

## Этап 1 — инвентаризация реальных данных

Сначала исследуй реальный код игры.

Нужно собрать максимально полный каталог всего, что потенциально можно использовать для анализа эксперимента, включая:

- состояния;
- события;
- временные отметки;
- координаты и направления;
- стрельбу и наведение;
- оружие и боеприпасы;
- попадания, промахи, траектории и ранения;
- подавление и восстановление;
- восприятие и обнаружение;
- движение;
- поведение и решения ИИ;
- выполнение программы;
- журнал и диагностику;
- результаты одиночных и серийных прогонов.

Для каждого источника укажи минимум:

- стабильный ID;
- русское название;
- категорию;
- описание;
- реальный источник в коде;
- тип данных;
- единицы;
- субъект/объект;
- состояние или событие;
- когда значение доступно;
- возможные агрегации/группировки;
- статус доступности.

Статусы обязательны:

- `доступно сейчас`;
- `вычисляется`;
- `нужна будущая телеметрия`.

Не выдавай желаемую будущую телеметрию за существующую возможность.
