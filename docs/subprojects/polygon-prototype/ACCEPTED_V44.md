## Важное примечание о хранении исходника

Контрольная сумма выше является канонической идентичностью принятого файла. Исходный HTML был предоставлен пользователем как файл разговора.

На момент фиксации статуса доступный GitHub-коннектор искажал большой файл при передаче через текстовое поле; проверки контрольных сумм это обнаружили. Поэтому повреждённая копия намеренно **не была объявлена каноническим v44**. Нельзя заменять указанный SHA похожей или частично восстановленной версией.

Когда используется среда с прямым доступом к рабочей копии Git, в репозиторий следует положить именно файл с указанным SHA-256 без каких-либо изменений. До такой побайтной проверки запись в этом документе остаётся источником идентичности принятого артефакта.
