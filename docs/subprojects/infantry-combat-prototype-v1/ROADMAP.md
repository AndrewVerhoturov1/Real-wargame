# Первый прототип пехотного боя

## Цель

Один пехотный отряд атакует другой. Оружие: винтовки, ППШ, пулемёт. Главная проверка — понятное поведение ИИ в атаке и обороне.

## Принцип

Код даёт физику, факты и безопасное исполнение действий. Graph v2 выбирает поведение. Испытательный полигон проверяет физику и параметры отдельно от поведения.

## Будущее испытательного полигона

После первого visual-стенда приложение должно развиваться в двух направлениях:

1. тысячи и десятки тысяч математических headless-прогонов для статистики и калибровки;
2. десятки и сотни визуальных прогонов для проверки конкретных seed и подтверждения статистических выводов.

Полноценный batch runner, worker pool и статистические панели не входят в Stage 9V, но архитектура Stage 9V должна учитывать их заранее.
