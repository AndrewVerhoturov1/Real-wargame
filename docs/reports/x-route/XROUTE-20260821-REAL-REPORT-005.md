## Кратко для пользователя

Режим report_only хранит каждый ответ в одной постоянной ветке отчётов, чтобы все безопасные отчёты собирались отдельно от продукта. Это упрощает поиск истории, проверку результатов и подтверждение того, что продуктовые файлы не менялись.

## Полный подробный ответ

В режиме report_only задача ограничена созданием отчёта. Постоянная ветка отчётов нужна для того, чтобы ответы разных запусков X-маршрута находились в одном предсказуемом месте.

Такой подход позволяет:

- не смешивать отчёты с разработкой продукта;
- сохранять последовательную историю проверок;
- проще проверять, какие отчёты были созданы;
- избегать создания множества временных веток для безопасных документальных задач.

В этом режиме нельзя менять продукт, создавать PR, выполнять слияние или деплой. Разрешено только подготовить и доставить отчёт.
