## Кратко для пользователя
Real-Wargame — прототип 2D tactical command game и лаборатория поведения отдельного солдата. Проект использует Vite, TypeScript, PixiJS 8, HTML/CSS и Node.js. Основная текущая область — тактическая симуляция, AI Runtime, редакторы и инструменты для экспериментов с поведением юнитов.

## Полный подробный ответ
Репозиторий содержит основу тактической 2D-игры с отдельным исследовательским слоем для поведения бойцов. В проекте развиваются симуляция, тактические знания, AI Runner/Runtime, редакторы и визуализация через PixiJS.

Активные направления включают Utility AI, GraphRunner, Blackboard, память бойца, карту опасности, территориальный контекст и объяснение решений ИИ. Также поддерживается RTS-карта, рельеф, лес, укрытия и видимость.

Пользовательский запуск описан через Run-Real-Wargame-Lab.bat. Репозиторий использует ветку real-wargame-preview как ветку приёмки разработки.
